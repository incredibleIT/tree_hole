# 产品简报：以外

## 概要

「以外」是一个公益开源的情感表达平台。它只做一件事：让每个人有机会把与错过的人之间的故事，郑重地写下来。

"世间好多遗憾，一切都有替代，但除了你以外。"——这句话是「以外」的灵魂。在这个平台上，每个用户一生最多只能落笔三篇故事。没有评论、没有点赞、没有信息流、没有通知。故事一旦落笔，永远清晰存在，不可删除，只能选择"合上"。

这不是一个社交产品，而是一种"场所"——你走进来，安静坐下来，写一封不会送达的信，然后离开时觉得自己轻了一点。

## 要解决的问题

人这一辈子，总会错过某个人。也许是没有说出口的话，也许是一个没有转身的背影，也许是当时以为来日方长的"下次再说"。

但今天没有任何一个地方能承接这种情感：

- **社交平台**太嘈杂，错过的心事不适合被围观和点赞
- **树洞/秘密类应用**追求刺激和互动，把遗憾变成了娱乐
- **日记/备忘录**只有自己在看，缺少一种"被世界见证"的仪式感
- **写信**是好的方式，但你不知道寄给谁，也没有人替你保存

错过的人，无处安放。这些故事散落在脑海深处，随着时间模糊，却永远不会消失——因为没有人为它们创造一个"存在的空间"。

## 解决方案

「以外」为这些故事创造一个专属的、克制的、永久的空间。

**落笔仪式：** 发布不叫"发布"，叫"落笔"。落笔前有一分钟的静默、三个温和的问题、一声笔落纸上的声音。整个过程不是技术操作，而是一场和自己过去的告别。

**极致稀缺：** 一生最多三篇。草稿可以改无数次，但出口只有三次。这意味着每一篇都是经过深思的、掏心掏肺的。

**反社交设计：** 没有评论、没有关注、没有搜索、没有排行榜。唯一的互动是"共鸣"——一个短暂的匿名符号，像有人在黑暗中轻轻点了一下头。

**永久清晰：** 故事永远不会褪色、不会被算法降权、不会消失在信息流里。它就在那里，像刻在石头上的字。

## 为什么不同

现有的匿名社交产品（树洞、秘密、一罐等）本质上都在追求"更多内容、更多互动、更高留存"。它们的商业模式要求用户持续产出和消费。

「以外」恰恰相反——它的设计目标是**让用户用得越少越好**。三篇故事用完，你就"毕业"了。我们不需要你回来。我们只希望你写的那三篇，是真诚的。

这不是一个产品逻辑，是一种价值观：**有些东西的价值恰恰在于它的稀缺和不可复制。**

## 服务的人

**核心用户：** 所有有过"错过"经历的人——不论年龄、职业、关系类型。可能是错过了初恋，可能是错过了挚友，可能是错过了陪伴童年的邻居，甚至是一只陪伴多年的宠物。

**他们的需求：** 一个安静的、不被打扰的空间，把那些一直想说却无处说的话，郑重地写下来。不是为了被谁看到，而是为了给自己的遗憾一个"落点"。

**成功标准（对用户）：** 落笔之后，感觉轻了一点。

## 成功标准（对项目）

由于是公益开源项目，衡量标准不同于商业产品：

- **落笔率：** 进入平台的人中，有多少最终完成落笔（目标：5-10%）
- **内容深度：** 平均写作时长（目标：30分钟+，说明用户在认真对待）
- **社会传播：** 自然分享和口碑（目标：概念验证阶段积累1000+等待列表）
- **社区贡献：** GitHub 开源仓库的星标数和代码贡献者数量（长期指标）

## 范围

### 第一版（概念验证网站 · 1-2周）

**做什么：**
- 每天展示一篇故事（只读，不能写）
- 种子内容由创作者本人先落笔写入
- 极简界面：未闭合圆符号 + 品牌标语
- 邮箱收集（"我想落笔"等待列表）

**不做什么：**
- 注册/登录系统
- 写作功能
- 任何形式的社交互动

### 第二版（开放写作 · 1-3个月）

**做什么：**
- 一生三篇的落笔机制
- 完整仪式流程（静默 → 三问 → 落笔音 → 散步动画）
- 匿名身份生成（无需手机号）
- 随机单篇故事展示
- 共鸣按钮
- 合上功能

**不做什么：**
- 评论、点赞、关注、搜索、通知、排行榜、个人主页
- 原生App
- 任何广告和付费功能

### 远期考虑（不承诺时间线）

故事温度、手写体渲染、封存日期、回信系统、以外地图、实体明信片、城市漫步路线等。

## 愿景

如果「以外」成功了，它不会成为下一个十亿用户的产品。但它可能成为一种文化符号——

人们会说"我把它写在了'以外'里"，就像说"我写了一封信"。

它会成为每一代年轻人第一次面对"错过"时，找到的那个安静的角落。它会成为城市文化的一部分——街角的实体信箱、毕业季的遗憾墙、旅途中偶遇的一个故事。

它不追求增长。它追求**意义**。

而意义，是最难被复制的护城河。

## 项目属性

- **性质：** 公益开源项目，代码托管于 GitHub
- **团队：** 独立开发者，一人维护
- **冷启动内容：** 由创作者本人率先落笔，作为平台种子故事
- **防重复注册：** 接受该限制——「一生三篇」是产品哲学而非技术枷锁，真正的约束来自用户对自身承诺的尊重
