# 设计系统：以外

## 1. 视觉主题与氛围

一个极度克制、呼吸感极强的界面，像深夜里一间只点了一盏灯的旧书房。

氛围是**安静的仪式感**——不是冷漠的极简，而是温暖的留白。每一处元素都有存在的理由，每一个像素都在为"错过"这个情感主题服务。设计哲学与产品哲学一致：**做减法，直到剩下的每一样东西都不可替代。**

- **密度：** 2（画廊级空气感）——页面只承载一篇故事，不需要信息密度。大量留白让阅读成为独处
- **变化度：** 5（克制的不对称）——首页故事卡片居中偏左，仪式流程用精确的居中对称表达庄重感，但导航和次要页面保持微妙偏移
- **动效强度：** 6（有意识的流体动效）——落笔仪式是核心：静默倒计时的呼吸节奏、笔落纸声的瞬间、散步动画的远去。动效只在仪式和情感节点出现，日常界面保持安静

**整体感受：** 像翻开一本旧日记本，纸张泛黄但字迹清晰。不是"好看的设计"，而是"让人想安静下来的设计"。

## 2. 色彩体系与角色

整体色彩方案模拟**深夜阅读**的视觉体验：温暖但不明亮，深色但不压抑。

### 浅色模式（日间阅读）

- **宣纸白** (#FAF9F6) — 主背景色，带极微暖色调，模拟旧纸张质感，不是刺眼的纯白
- **素面** (#FFFFFF) — 卡片和容器填充，与背景形成极细微层次
- **墨痕** (#1C1917) — 主要文字色，Stone-900 深度，比纯黑温润
- **旧信纸** (#A8A29E) — 次要文字，描述、元数据、时间戳，Stone-400
- **薄雾边** (rgba(168,162,158,0.15)) — 卡片边框和结构分割线，几乎看不见
- **琥珀灯** (#B45309) — 唯一强调色，Amber-700。用于落笔按钮、仪式确认、共鸣按钮。像深夜书桌上那盏暖色台灯。饱和度 75%，克制而温暖

### 深色模式（深夜落笔 — 默认模式）

- **深墨** (#0C0A09) — 主背景色，Stone-950，深夜的底色
- **夜纸** (#1C1917) — 卡片和容器填充，Stone-900
- **月光字** (#E7E5E4) — 主要文字色，Stone-200
- **远处灯** (#78716C) — 次要文字，Stone-500
- **暗影线** (rgba(120,113,108,0.1)) — 结构分割线
- **暖灯芯** (#D97706) — 强调色，Amber-600。深色模式下略微提亮，保持温暖感

### 色彩规则

- 强调色全局仅一处：落笔/确认/共鸣等**情感动作**触发点
- 禁止霓虹色、紫色渐变、蓝色光晕——这是安静的地方，不是夜店
- 禁止纯黑 `#000000`——用 Stone-950 代替，更有温度
- 共鸣按钮的光点动画使用强调色的 40% 透明度脉冲
- 仪式流程中的背景色随阶段微变：静默阶段最暗，落笔瞬间微亮（+2% 亮度），散步动画渐暗回归

## 3. 字体规则

### 中文正文

- **正文字体：** 思源宋体（Noto Serif SC）或 霞鹜文楷（LXGW WenKai）
- **用途：** 故事正文、落笔仪式文字、所有中文内容
- **理由：** 宋体/楷体承载"书写"和"信"的质感。当用户在阅读一篇关于错过的故事时，字体本身就在说"这是一封认真的信"
- **行高：** 1.8-2.0，比常规宽松，模拟信纸的阅读节奏
- **字间距：** 正常，不压缩
- **最大行宽：** 32 个中文字符（约 64ch），避免长行破坏沉浸感

### 界面文字

- **界面字体：** Geist 或 Satoshi
- **用途：** 导航、按钮、标签、元数据、管理后台
- **理由：** 干净、中性、不抢故事的风头
- **字重层级：** 通过字重（400/500/600）和颜色区分层级，不使用超大字号

### 等宽字体

- **等宽字体：** Geist Mono
- **用途：** 落笔计数（"第 1 篇 / 共 3 篇"）、静默倒计时数字、管理后台数据

### 禁止

- 禁止 Inter（太常见，缺乏个性）
- 禁止系统默认字体（宋体 SimSun、微软雅黑）——它们承载的不是"信"的感觉
- 禁止任何装饰性字体（手写体、卡通体）——故事的文字本身就是最好的装饰

## 4. 组件样式

### 故事卡片（核心组件）

- 无阴影、无边框——故事直接浮在背景上，像页面上本来就有的文字
- 标题使用正文字体，不额外加粗，与正文视觉一致
- 卡片最大宽度 640px，居中偏左（左侧留 15% 额外空白）
- 卡片间距：至少 4rem，阅读时一次只能聚焦一篇
- 悬停效果：无悬停变化——故事不需要"可点击"的暗示，它就在那里

### 按钮

- **落笔按钮：** 强调色填充，圆角 0.5rem（克制的圆角，不是胶囊形）。按下时 -1px 位移，模拟"笔尖触纸"的触感
- **次要按钮（加入等待列表等）：** 透明背景 + 1px 强调色边框，悬停时极微的边框加粗（1px → 1.5px）
- **共鸣按钮：** 一个极小的圆点（8px），点击后扩散为光晕动画然后消散。不是传统按钮，是一个"点头"的动作
- 禁止渐变按钮、禁止发光效果、禁止自定义鼠标指针

### 输入框

- 邮箱输入：标签在上方，输入框无圆角（方形），1px 细边框
- 聚焦时：边框变强调色，无外发光
- 草稿编辑器：无边框，直接是一个可编辑的文字区域，与阅读模式视觉一致——"写"和"读"应该是同一种体验
- 字数限制提示：极小的灰色数字，在右下角

### 加载状态

- 骨架屏：用两条短横线模拟文字行的位置，颜色为背景色的 +3% 亮度，带缓慢的微光扫过效果（4 秒周期）
- 禁止旋转加载图标——这个平台不应该有任何"等待"的焦虑感

### 空状态

- 草稿箱为空时：一行楷体文字"还没有开始写的故事"，下方一个极淡的"+"号
- 故事读完了（概念验证阶段）：一行文字"今天的故事已经读完了"，下方显示邮箱输入框
- 禁止通用的"暂无数据"文案

### 仪式组件

- **静默倒计时：** 页面中央一个缓慢呼吸的圆环（3 秒一个呼吸周期），配合倒计时数字。背景逐渐变暗（每分钟 -1% 亮度）
- **三问确认：** 每次只显示一个问题，居中出现，下方一个"是"字按钮。问题之间 2 秒淡入淡出过渡
- **笔落纸声：** 纯音频触发，无视觉组件。声音是一个轻柔的钢笔尖触纸声（0.8 秒）
- **散步动画：** 全屏渐暗后，一个小小人影从屏幕中央缓慢走向右下角，逐渐缩小、模糊、消失。动画时长 8-12 秒。使用 CSS 动画 + Framer Motion

## 5. 布局原则

### 核心布局

- 最大宽度约束：960px（内容区），居中
- 首页：单栏布局，一篇故事占据整个视口高度（min-h-[100dvh]），下方是极淡的邮箱输入框
- 阅读页：故事文字居中偏左，左侧额外留白形成"装订线"视觉
- 写作页：全屏编辑器，无边框无装饰，像在信纸上写字
- 仪式页：全屏居中，所有元素精确居中，背景全黑（深色模式）
- 管理后台：简洁的单栏仪表盘，数据密度 4（比主站稍密）

### 间距哲学

- 大量留白是设计的核心语言——空白不是"浪费的空间"，而是"给情感留出的呼吸空间"
- 段落间距：2rem（中文排版需要更多呼吸）
- 区块间距：clamp(3rem, 8vw, 6rem)——随视口自适应
- 页面边距：移动端 1.5rem，桌面端 2rem

### 禁止

- 禁止 3 列等宽卡片布局——这个平台不展示"功能列表"
- 禁止侧边栏导航——所有导航极简，通过顶部文字链或底部按钮完成
- 禁止元素重叠——每个元素占据自己清晰的空间
- 禁止 Flexbox 百分比计算——使用 CSS Grid 处理复杂布局

## 6. 响应式规则

### 移动端优先（< 768px）

- 所有布局收为单栏，无例外
- 故事文字最小 16px（移动端阅读舒适度）
- 触摸目标最小 44px
- 仪式流程在移动端完全保留（静默倒计时、三问、散步动画）
- 禁止横向滚动——溢出是严重错误
- 导航收为顶部简洁菜单

### 平板（768px - 1024px）

- 故事区域保持单栏居中
- 管理后台可采用 2 列网格

### 桌面（> 1024px）

- 最大宽度 960px 居中，两侧大量留白
- 管理后台最大宽度 1200px

### 字体缩放

- 故事标题：clamp(1.25rem, 3vw, 1.75rem)
- 故事正文：clamp(1rem, 2.5vw, 1.125rem)
- 界面文字：最小 0.875rem

## 7. 动效与交互

### 动效哲学

动效只在**情感节点**出现。日常界面保持安静，仪式流程承载全部动效预算。

### 弹簧物理参数

- 默认：stiffness 100, damping 20——沉稳、有重量感
- 仪式过渡：stiffness 60, damping 25——更缓慢、更庄重
- 共鸣光点：stiffness 150, damping 12——轻快、像远处的信号

### 仪式动效序列

1. **进入仪式：** 页面元素淡出（1.5 秒），背景渐暗至纯黑
2. **静默阶段：** 呼吸圆环（3 秒/周期），倒计时数字每秒更新。持续 60 秒
3. **三问阶段：** 每个问题 2 秒淡入，点击"是"后 1.5 秒淡出，下一个 2 秒淡入
4. **落笔瞬间：** 笔落纸声触发（0.8 秒音频），屏幕微亮（+2% 亮度，0.3 秒）
5. **散步动画：** 人影从中心出现（1 秒淡入），缓慢向右下角移动（8-12 秒），逐渐缩小和模糊（最后 3 秒），消失后 2 秒黑屏，然后淡入"落笔完成"页面

### 日常动效

- 页面切换：0.3 秒交叉淡入淡出
- 列表加载：级联延迟（每个项目延迟 0.05 秒），瀑布式出现
- 共鸣按钮：点击后光点扩散（0.6 秒）然后消散（1.2 秒），不可逆
- 草稿保存：右下角一个极淡的"已保存"文字，2 秒后淡出

### 性能规则

- 只使用 `transform` 和 `opacity` 做动画——禁止动画 `top`、`left`、`width`、`height`
- 散步动画使用 CSS `will-change: transform` 预优化
- 支持 `prefers-reduced-motion`：所有动画降级为简单淡入淡出
- 音效可全局静音

### 持续微动效

- 首页等待列表计数：数字变化时有 0.2 秒的滚动过渡
- 落笔按钮：极微的呼吸脉冲（2% 透明度变化，4 秒周期），暗示"它在等你"

## 8. 反模式（禁止清单）

以下模式在本项目中严格禁止：

- **禁止表情符号** —— 任何界面元素、按钮、标题中都不使用 emoji
- **禁止 Inter 字体** —— 太常见，缺乏"信"的质感
- **禁止纯黑 `#000000`** —— 用 Stone-950 代替
- **禁止霓虹发光/外阴影** —— 这是安静的地方
- **禁止过饱和强调色** —— 温暖克制，不是炫目
- **禁止渐变文字** —— 标题不使用渐变填充
- **禁止自定义鼠标指针** —— 使用系统默认
- **禁止元素重叠** —— 每个元素占据自己的空间
- **禁止 3 列等宽布局** —— 不适用于本产品
- **禁止通用占位名** —— 不使用"张三""李四"等，管理后台使用真实数据或"匿名用户"
- **禁止 AI 营销话术** —— 不使用"赋能""无缝""极致体验"等词。文案保持朴素
- **禁止填充文字** —— 不使用"向下滑动""探索更多"等引导语。内容本身吸引用户
- **禁止弹跳箭头/滚动提示** —— 页面自然流动
- **禁止旋转加载动画** —— 使用骨架屏
- **禁止信息流/推荐流** —— 反社交设计核心约束
- **禁止评论/关注/搜索 UI** —— 反社交设计核心约束
- **禁止深色模式下的浅色卡片** —— 深色模式使用统一的深色调色板

## 9. 无障碍与降级

- 所有动画支持 `prefers-reduced-motion: reduce` 媒体查询——降级为 0.3 秒淡入淡出
- 所有音效支持全局静音开关——右上角一个极小的喇叭图标
- 仪式流程的静默阶段：屏幕阅读器播报"一分钟静默开始"和剩余时间
- 色彩对比度：所有文字与背景对比度 ≥ 4.5:1（WCAG AA）
- 触摸目标：移动端所有可交互元素 ≥ 44px

## 10. Google Stitch 生成指引

使用 Stitch 生成屏幕时，遵循以下优先级：

1. **首先生成首页**（概念验证阶段）：一篇故事 + 邮箱输入框，深色模式
2. **然后生成仪式流程**：静默 → 三问 → 落笔 → 散步，4 个屏幕序列
3. **然后生成写作页**：全屏编辑器 + 草稿箱列表
4. **最后生成管理后台**：故事队列 + 等待列表 + 数据看板

每个屏幕生成前，先确认色彩方案（深色模式优先）、字体（思源宋体/霞鹜文楷）、和无表情符号规则。
